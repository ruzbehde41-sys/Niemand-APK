# Safety and legal boundaries

Use these tools only on applications, devices and data you own or are explicitly authorized to assess.

Permitted project focus includes app compatibility research, static inspection, debugging, interoperability, defensive security and educational analysis within applicable law and license terms.

Do not use this repository to bypass authentication, access controls, DRM, subscription/payment systems or software licensing; extract private user data; compromise accounts; or redistribute proprietary application code or assets without permission.

Before publishing findings, remove secrets and personal data and consider responsible disclosure. Laws and contractual restrictions vary by jurisdiction; obtain qualified advice where needed.
