# Security policy

## Scope
This repository contains Android development, APK inspection and mobile automation research. Treat APKs, archives, scripts and repositories from outside sources as untrusted.

## Safe handling
- Do not execute unknown APKs or scripts on a primary device.
- Prefer static, read-only inspection in an isolated workspace.
- Do not bypass authentication, access controls, DRM, licensing or payment protections.
- Never publish credentials, tokens, signing keys, customer data or private dumps.
- Report suspected vulnerabilities privately to the repository owner before public disclosure.

## Supported versions
Security fixes are handled on a best-effort basis. Include tool versions, device/OS details and reproducible evidence in reports, with sensitive data removed.
