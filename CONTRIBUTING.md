# Contributing

Contributions should be focused, reproducible and documented.

## Before submitting
- Explain the problem and intended outcome.
- Identify supported Android versions, architectures and Termux constraints.
- Check licenses and provenance of dependencies and samples.
- Keep secrets, signing keys, private data and generated binaries out of Git.
- Add or update tests for scripts and tools.
- Include exact test commands and observed results; do not claim unrun tests passed.

## Changes
Prefer small commits with descriptive messages. Avoid unrelated formatting or generated files. For APK research, preserve original samples and document authorization and scope.
